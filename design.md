# Family Vitals Design System

## Overview
Family Vitals is a calm, dark, high-contrast health interface. It prioritizes readable metrics, quiet family sharing, and low visual noise. The experience should feel steady and trustworthy rather than clinical or gamified.

## Color usage
- White for primary text, key metrics, and primary actions
- Forest-black backgrounds for immersive calm
- Muted white for secondary labels and timestamps
- Soft success/warning/danger tints only for reading status (normal / elevated / high), never as large brand fills

## Typography
- Geist for headings and metric emphasis
- Geist Mono for labels, timestamps, tables, and form metadata
- Metric values should be large, sparse, and instantly scannable

## Layout principles
- Dashboard first: latest readings + family status
- Cards for BP, Pulse, Blood Sugar
- Tables/lists for history
- Generous section spacing, tighter internal data spacing
- Mobile-first PWA layout with sticky primary actions

## Components
- Primary button: white fill, dark text
- Secondary button: outlined/transparent
- Cards: flat dark surfaces with thin borders, no heavy shadows
- Inputs: compact, high-contrast, 40px height
- Status chips: minimal, muted, text-forward

## Do's and Don'ts
- Do keep the UI monochrome-first and calm
- Do make vital numbers the strongest visual element
- Do use family context clearly without clutter
- Don't use loud multi-color medical dashboards
- Don't add playful or social-media chrome
- Don't hide critical health status behind dense decoration
